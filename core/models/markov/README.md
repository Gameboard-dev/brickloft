# Rule programs from MarkovJunior

The files in this folder are copied, unchanged, from Maxim Gumin's
MarkovJunior: <https://github.com/mxgmn/MarkovJunior>, at commit
`42aaf24bcf54ae164fba49c0a59348297904a676`, read on 2026-11-16. They are
under the MIT licence in [LICENSE](LICENSE), which is the original's own
licence file and covers the whole of that repository.

| Here | There | What it is |
|---|---|---|
| `models/*.xml` | `models/` | nine programs: Apartemazements, CarmaTower, ModernHouse, SeaVilla, PillarsOfEternity, Escher, StrangeDungeon, Hills, Partitioning |
| `resources/rules/` | `resources/rules/` | the larger patterns of CarmaTower, ModernHouse and SeaVilla, as .vox files |
| `resources/tilesets/` | `resources/tilesets/` | the tilesets those programs use: Paths, Partition, PartitionedEdges, MarchingHills, OrientedStairs, Escher |
| `resources/palette.xml` | `resources/palette.xml` | the colour of each letter |

The original's README credits one of these programs to someone else's
work: CarmaTower is "a proceduralization of a voxel scene by Antoine
Lendrevie" (<https://twitter.com/Sir_carma/status/851883489628704768>).
The program and its patterns are Gumin's and are in his repository under
his licence; the building's look is Lendrevie's.

To take a newer copy, copy the same files again from the original and
change the commit above. Nothing here is edited by hand.
