brickloft-generate: a mesh from a picture, and a picture from a prompt,
with models that run on this computer.

  brickloft-generate check [--verify]
      What this computer can do: the graphics device and its memory, the
      weights that are present, and whether each step can run. With
      --verify, every weights file's SHA-256 is checked as well.

  brickloft-generate fetch <triposr|sd15> [--accept-licence]
      Shows the model's licence. With --accept-licence, downloads its
      weights from Hugging Face; an interrupted download is carried on.

  brickloft-generate picture --prompt "an oak barrel" --out <folder>
                             [--seed N] [--count K] [--steps S]
      K pictures of the prompt (1 to 8), ranked by how well each is
      likely to make a mesh. The prompt is at most 500 characters.

  brickloft-generate mesh --picture <file> --out <file.glb>
                          [--no-cutout] [--no-level] [--resolution N]
      A mesh of the object in the picture, with a colour at each vertex.
      --no-cutout for a picture that is already see-through around the
      object. --resolution from 32 to 256 (128 if not given).

  brickloft-generate serve
      The same commands as lines of JSON on standard input, with the
      models kept loaded between them.

Options for all:
  --weights <folder>   where the weights are kept
  --device <auto|cuda|vulkan>
  --watch-stdin        stop when standard input is closed

Every answer is a line of JSON on standard output. docs/generate.md in
the Brickloft repository describes them.
